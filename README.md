# 📖 Text Tales

**A 5-question story guessing game for remote friends!**

Play with anyone, anywhere — no downloads, no accounts needed.

---

## 🎮 How to Play

1. One person is the **Keeper** (sets a secret)
2. The other is the **Sleuth** (asks 5 yes/no questions)
3. The Keeper replies with **1 word + 1 emoji**
4. The Sleuth guesses the secret!

---

## 🔎 Game Rules

- Keeper thinks of a **Character + Object + Location**
- Keeper shares **3 emoji clues**
- Sleuth asks up to **5 yes/no questions**
- Keeper answers with hints like: `Yes ✅` `No 🚫` `Sorta 🌓`
- Sleuth makes a final guess — exact match wins! 🏆
